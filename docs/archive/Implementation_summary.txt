================================================================================
DATA PERSISTENCE MODEL
================================================================================

User Login Process:
──────────────────

First Time:
  User → Email+Password → OTP entered → Credentials encrypted on device
                                            ↓
                        Stored in Keychain/Keystore (never sent to cloud)
                                            ↓
                        SQLite stores: login timestamp, last access
                                            ↓
                        Sighting records saved locally (separate from auth)

Second Time (Next Day):
  App Launch → Check Keychain/Keystore → Email found
                            ↓
                        Auto-login ✅
                            ↓
                        Show home screen
                            ↓
                        Load sightings from SQLite

Logout:
  User clicks Logout → Delete email from Keychain
                       Delete session tokens
                       SQLite data remains (optional cleanup)

Cloud Backup:
  (Optional) User submits sighting → Data synced to backend API
             Expert reviews → Results saved to cloud

- Only notify experts, not users: Save 50%
